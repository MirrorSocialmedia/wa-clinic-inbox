# WA Clinic Inbox — 逐店 Rollout Checklist

> 用法：**一日一店慢慢嚟**。每店喺度複製一份，逐項打勾。全部 ✅ 先算該店 onboard 完成。
> 打印：直接 print 呢頁（A4 兩頁內）。

---

## 店名：____________________　日期：________　負責人：________

### A. 上線前置（技術 — 指揮大神行）
- [ ] WhatsApp App 更新最新版（前台部手機）
- [ ] 該號碼活躍 ≥ 7 日（新號碼要養）
- [ ] Embedded Signup scan QR 完成（該號碼 bind 入 Cloud API）
- [ ] 揀匯入 6 個月歷史（App 內設定）
- [ ] history import 完成 + 核對（抽 5 條眼對）
- [ ] `Clinic.waPhoneNumberId` 寫入 DB（admin 頁或 seed）
- [ ] 該店醫生名單入 `greetingConfig`（地址/營業時間/醫生/常見 FAQ）
- [ ] 前台帳號開通（email + 密碼，role=STAFF 綁定該店）

### B. 前台 15 分鐘教學（重點口徑）
1. **覆客（5 min）**：網頁 inbox 見到新訊息 → 未讀紅圈 → 撳開對話 → 直接打字覆（手機 App 嗰邊亦會見到，兩邊同步）。
2. **草稿三掣（5 min）**：AI 會預備好回覆草稿，三個掣 —
   - ✅ **用呢條**（照發）
   - ✏️ **改少少**（改完再發）
   - ❌ **唔使**（棄用，自己寫）
   - 口頭訣：**「AI 只係草稿，最後按掋嘅係你」**。
3. **預約卡（3 min）**：病人話想預約 → AI 出預約卡（醫生/日期/時間）→ 病人揀完 → 你見到「待確認」→ 核實後撳確認（或病人話「已經喺 Apricot 落單」就撳已確認）。
4. **兩條鐵律（2 min）— 一定要背熟：**
   - 🚫 **App 唔准 uninstall**（部手機 WhatsApp 照用）
   - ⏰ **至少每 13 日開一次 App**（唔開 13 日會斷 coexistence）

### C. 上線日驗證
- [ ] 前台盲測：唔睇文檔獨立完成「收訊息 → 用草稿覆 → 處理預約卡 → 確認」全程
- [ ] 兩個 browser 同時登入同一店：A 發訊息 B 實時見到；A 標 RESOLVED B 同步
- [ ] quality_rating = GREEN（`/admin` 睇）
- [ ] 該店今日 webhook 有 traffic（健康自檢唔彈 stale 警報）

### D. 上線後 7 日（跟進）
- [ ] 每日瞟一眼 quality_rating（全 GREEN）
- [ ] 前台有冇問題 / 唔習慣（第一週密集跟）
- [ ] 零事故 7 日 → 該店標記穩定，下一間

## 常見問題速查

| 症狀 | 原因 | 處理 |
|------|------|------|
| 網頁冇新訊息但 App 有 | webhook 斷（App uninstall / 13 日冇開） | 查 `/admin` alerts（webhook_stale）；重申鐵律；重開 App |
| 冇 AI 草稿冇標籤 | AI 機斷線 | inbox 照收發（graceful degradation）；查 AI breaker 警報 |
| 訊息堆住冇人覆 | 前台唔喺 | 正常（系統唔會自動發出）；睇 FRT 中位數 |
| quality_rating 跌 YELLOW/RED | 被 ban 前哨 | **立即減量**，查該號發送行為；`/admin` 有 HIGH 警報 |
